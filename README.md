# 我的时间执行表

一个可安装到手机桌面的个人时间管理 PWA。它不是原生 App，不需要服务器或数据库。

## 主要功能

- 按当前时间显示正在进行或即将开始的安排
- 显示执行标准与实时倒计时
- 自由编辑、新增、删除工作一、工作二和恢复日安排
- 每周选择工作一的 3 天，剩余工作日自动使用工作二
- 页面打开时到点弹窗
- 导出本周 `.ics`，由手机日历在锁屏或页面关闭后提醒
- 安装到手机桌面并离线打开
- 日程、打卡与提醒设置仅保存在当前设备浏览器中

## 发布到 GitHub Pages

1. 将仓库可见性改为 **Public**。
2. 打开 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 **main**，目录选择 **/(root)**，点击 **Save**。
5. 等待部署完成后访问：<https://klx-small.github.io/daily-schedule-countdown/>

## 安装到手机桌面

- **iPhone/iPad**：用 Safari 打开上面的 Pages 地址，点击“分享”→“添加到主屏幕”→“添加”。
- **Android**：用 Chrome 打开地址，点击页面内“安装到手机桌面”；若未出现系统安装框，使用浏览器菜单中的“安装应用”或“添加到主屏幕”。

## 提醒说明

PWA 打开时可显示页面弹窗。为了在锁屏或完全关闭页面后稳定收到提醒，请在“提醒”页面导出本周系统提醒，并导入手机日历。

## 数据说明

页面使用 `localStorage` 保存个人修改。清除该网站的数据、更换浏览器或更换设备后，内容不会自动同步。GitHub 仓库保留初始模板，不会记录你在手机上编辑的私人内容。
