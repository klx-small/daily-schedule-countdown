# 我的时间执行表

这是从个人排班表整理出的手机端单文件时间管理页面，不需要安装 App，也不依赖服务器、数据库或第三方组件。

## 已实现

- 按当前时间显示正在进行或即将开始的安排
- 显示执行标准和实时倒计时
- 工作一每周选择 3 天，剩余 3 天自动安排工作二
- 周日固定恢复日
- 每项独立打卡和开关提醒
- 页面打开时显示到点弹窗
- 导出本周 `.ics` 日历文件，供手机系统在锁屏或关闭网页后提醒
- 排班、打卡和提醒设置仅保存在当前设备浏览器中

## 使用方式

仓库为私有状态时：

1. 在 GitHub 中打开 `index.html`。
2. 下载 Raw 文件到手机。
3. 使用手机浏览器打开该文件。
4. 在“本周”确认工作一的 3 天。
5. 在“提醒”中开启页面弹窗，或导出日历提醒。

> 不同手机对本地 HTML 的系统通知支持不同。为了确保页面关闭后仍提醒，请使用“导出本周系统提醒”并导入手机日历。

## GitHub Pages

若以后希望获得固定的手机访问链接，可将仓库改为公开并在仓库 **Settings → Pages** 中选择从 `main` 分支根目录发布。公开前请注意：`index.html` 中包含个人作息安排。

## 数据说明

页面使用浏览器 `localStorage` 保存设置。清除浏览器网站数据、更换浏览器或更换设备后，原有打卡与设置不会自动同步。
